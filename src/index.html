FIRST-TIME CONNECTION

Get your console ready

PS5 setup

  1. On your PS5, open Settings → System → Remote Play.
  2. Turn on Enable Remote Play.
  3. Install the official PS Remote Play app on Windows.
  4. Sign in with the same PlayStation account as your console.
  5. Connect your controller to the PC and select your PS5.

Xbox setup

  1. On Xbox, open Settings → Devices & connections → Remote features.
  2. Enable remote features and run the remote-play test.
  3. Keep your console online.
  4. Open Xbox Remote Play and sign in.

REQUIRED WINDOWS DRIVER

Virtual gamepad driver

The mapper needs ViGEmBus installed to create a virtual DualShock 4. This is an archived, discontinued driver and is no longer maintained.

Install it only from the official project release page. Restart Windows after installation if the virtual controller does not appear.

IMPORTANT COMPATIBILITY LIMIT

This prototype creates a virtual DualShock 4, not a DualSense. PS Remote Play supports both controller types, but some PS5 games require DualSense-specific features or may reject a virtual DS4.
