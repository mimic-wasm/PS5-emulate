# GTA6-emulate

ConsoleBridge is a Windows desktop launcher for the official PlayStation and Xbox Remote Play experiences. It does not emulate PS5 or Xbox hardware. Your console runs the game and streams it to your PC through the platform's official service.

## Run
1. Install Node.js LTS on Windows.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm start`.

## PlayStation
Install the official [PS Remote Play app](https://remoteplay.dl.playstation.net/remoteplay/). In the app, select its installed executable and launch it.

## Xbox
Enable Remote Features on your Xbox, then open [Xbox Remote Play](https://www.xbox.com/remoteplay).

This starter does not copy game files, modify firmware, store account passwords, or bypass platform protections. It is independent and is not affiliated with Sony or Microsoft.
